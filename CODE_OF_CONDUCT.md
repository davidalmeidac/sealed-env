# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct, in full and without modification.

The canonical text — including the Pledge, Standards, Enforcement
Responsibilities, Scope, Enforcement Guidelines, and Attribution sections —
is available at:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A plain-text translation in many languages is available from the same site.

## Reporting

Concerns about behavior in this project's spaces (issues, pull requests,
discussions, code review, project chat, social-media accounts associated
with the project) can be reported privately to the maintainer:

- **Email:** [davidalmeidac@proton.me](mailto:davidalmeidac@proton.me)
- **Subject prefix:** `[CoC]` so the report is triaged quickly.

Reports will be reviewed and investigated promptly and fairly. Reporters'
identities will be kept confidential to the extent possible while addressing
the report.

## Why we adopt the Covenant verbatim

Two reasons:

1. **It's a known standard.** Most experienced open-source contributors have
   already read it and know what to expect. Adopting it verbatim removes
   ambiguity.
2. **It updates.** The Contributor Covenant is maintained at its canonical
   URL. By linking instead of copying, this project automatically inherits
   any future clarifications without requiring a separate PR here.

## Scope

This Code of Conduct applies to all project spaces and to public spaces when
an individual is representing the project. Examples of representing the
project include using an official project email address, posting via an
official social-media account, or acting as an appointed representative at
an online or offline event.
